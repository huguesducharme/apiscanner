# API Security Scanner
Консольная утилита на Go для статического (SAST) и динамического (DAST) анализа безопасности API и исходного кода. 
Проект предназначен для сигнатурного поиска приватных ключей и токенов в репозиториях, а также для базового аудита эндпоинтов на уязвимости из списка OWASP API Top 10.

# Функционал
    SAST: Рекурсивный сканер исходного кода. Ищет захардкоженные API-ключи, токены (Telegram, AWS, JWT) и пароли по регулярным выражениям.

    DAST: Модуль динамического анализа. Проверяет активные эндпоинты на BOLA (Broken Object Level Authorization), ошибки конфигурации безопасности и отсутствие Rate Limiting.

    Параллельная обработка: Сканирование файлов и отправка HTTP-запросов запараллелены через воркер-пулы на горутинах и каналах.

# Структура проекта
`cmd/apiscanner/` — точка входа, обработка CLI-аргументов и флагов.
`internal/sast/` — движок статического анализа и регулярные выражения.
`internal/dast/` — модуль отправки HTTP-запросов и проверок уязвимостей.
`internal/report/` — форматирование и вывод отчетов о найденных уязвимостях.
